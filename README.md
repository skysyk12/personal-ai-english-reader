# Margin — Personal AI English Reader

Margin 是一个本地优先的个人英文阅读器 MVP。当前版本支持 EPUB 与 PDF 阅读闭环：导入书籍、保存进度、选择原文、高亮、个人笔记，以及按学习角色调用 DeepSeek 讲解。产品界面采用已选定的 Reading OS 设计系统，信息密度和交互方式参考 Readwise Reader 与 Linear。

## 版本更新记录

### v0.4.0 — PDF 双模式与文本重排（当前版本）

这是目前最新的一次主要更新，目标是让用户自己决定“阅读内容”还是“查看原始版式”。

- 新增 PDF 文本重排模式，文字会根据阅读区域宽度重新换行。
- 保留 PDF.js 原版模式，完整显示图片、表格和页面版式。
- 阅读设置中可以随时切换“文本重排 / PDF 原版”，每本书会记住上次选择。
- 文本重排支持字号、行距和字体调整。
- 在服务端按页提取 PDF 文字，并在本地生成版本化 JSON 缓存，避免每次重新解析。
- 增加标题、段落、列表、英文断词和多栏阅读顺序识别。
- 两种 PDF 模式共享页码进度、高亮、笔记、文本选择和 AI 操作。
- 扫描件或图片型 PDF 无可提取文字时，显示明确提示并一键切换原版。
- 修复数百页 PDF 恢复远端页码时缓慢滚动、落点偏移和覆盖进度的问题。
- 完成桌面端、390px 手机端、键盘操作、减少动态效果和无障碍适配。

验证记录：使用 407 页的《The Economist [Mar 14th 2026]》测试，其中 397 页存在可重排文字；另外使用文字型 PDF 和扫描型 PDF 验证了正常重排与原版回退。

### v0.3.0 — PDF 导入与原版阅读

- 书库导入范围从 EPUB 扩展到 PDF。
- 导入时解析 PDF 元数据、总页数并保存本地副本。
- 新增 PDF.js 连续页面阅读器。
- 支持上一页、下一页、页码跳转、缩放、适合宽度和下载原文件。
- 保存 PDF 页码与阅读百分比。
- PDF 文字选择接入解释、翻译、句子分析、自由提问、高亮和笔记。
- 为后续文本重排保留 `pdf_default_mode` 和解析质量数据结构。

### v0.2.0 — Reading OS 与阅读体验改版

- 从 3 套视觉探索方案中确定 Reading OS 作为正式界面方向。
- 整体视觉参考 Readwise Reader 与 Linear，采用紧凑布局、低圆角、分层边框和单一靛蓝强调色。
- EPUB 默认改为连续上下滚动，分页阅读作为可选模式。
- 重构书库、阅读器、学习角色、笔记和设置页面。
- 增加可收起目录、AI 侧栏、阅读设置和全局快速命令。
- 完善窄屏和手机端响应式布局。
- 补全 DeepSeek 服务端调用、流式响应、错误提示和继续追问流程。

### v0.1.0 — 本地优先 MVP

- 建立 Next.js、React、TypeScript 和本地 SQLite 工程。
- 实现 EPUB 导入、书库管理、封面与元数据解析。
- 实现 EPUB 阅读、目录跳转和阅读进度保存。
- 实现原文选择、高亮和个人笔记。
- 提供小说沉浸阅读、学术英语阅读、雅思备考等学习角色。

- 接入 DeepSeek，由本地服务端保管 API Key。

- 确立单人、本地优先、不做登录与云同步的产品边界。

## 本地运行

环境要求：Node.js 20+、npm。

```bash
npm install
cp .env.example .env.local
npm run dev
```

然后打开 [http://127.0.0.1:3000/library](http://127.0.0.1:3000/library)。应用数据存放在项目的 `data/` 目录中，该目录已加入 `.gitignore`。

## 配置 DeepSeek

编辑 `.env.local`：

```dotenv
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

密钥只由服务端 API 路由读取，不会发送到浏览器，也不要提交 `.env.local`。修改环境变量后需要重启开发服务器。

## 已实现范围

- EPUB / PDF 导入、元数据解析、本地副本与书库管理
- EPUB 默认连续上下滚动，可在阅读设置中切换分页阅读；支持目录跳转、字号/行距/字体设置与阅读进度保存
- PDF 双模式：文本重排会按阅读宽度重新换行并支持字号、行距和字体设置；PDF.js 原版模式保留图片、表格与页面版式
- PDF 两种模式共享页码进度、文本选择、高亮、笔记和 AI 操作；阅读方式会按书保存
- 原文选择、高亮、个人笔记、从笔记返回原文锚点
- 学习角色预设、自定义角色、默认角色与 Prompt 预览
- DeepSeek 流式回答、继续追问、错误恢复、回答保存为笔记
- 中文操作界面，英文原文与中英双语 AI 输出
- 桌面优先，同时适配平板和手机窄屏
- Reading OS 统一视觉系统：紧凑布局、低圆角、边框分层、单一靛蓝强调色
- 全局快速命令：点击顶栏搜索入口，或按 `⌘ K` / `Ctrl K`

## 页面入口

- `/library`：书库与 EPUB / PDF 导入
- `/reader/[bookId]`：阅读器
- `/roles`：学习角色管理
- `/notes`：笔记与 AI 回答
- `/settings`：本地存储和模型配置说明

`/style-lab` 现已重定向到书库；视觉方案确认后不再作为正式产品页面保留。

## 当前边界

- PDF 文本重排基于可提取文字，首次打开时会在本地生成缓存；扫描件/图片型 PDF 暂不做 OCR，会提示切换到原版阅读。
- 多栏、表格和图文混排页面会尽量按栏重建阅读顺序；需要核对视觉关系时请切换到 PDF 原版。
- AI 真实回答需要你自己的 DeepSeek API Key；密钥只保存在本机 `.env.local`，不会出现在设置页或前端请求中。
- 本项目面向个人单机使用，暂未包含账号、云同步和多设备协作。
